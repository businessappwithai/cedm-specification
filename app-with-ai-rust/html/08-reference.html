Reference

Everything the language offers, on one page. Two files are the authority: language/yaml/eml.schema.json says which keys a model may carry, and language/appwithai-language.json says what the values in them mean — when this page and either file disagree, the file wins.

Two syntax rules that bite

fields and decisionTable carry JSON inside a YAML string: wrap the whole value in single quotes so JSON's double quotes survive. And quote any scalar holding : , a leading * or a # — a cron source, a colour, a label like "Start: Lead Captured" — or YAML reads it as something else.

Generator targets

One model, three --stack values. They differ in what they write, never in what they understand — all three read the same parsed model, so a directive that changes meaning changes it for all of them.

--stackWritesStandalone?
node-rest (default)A dependency-free node:http app over a JSON-file datastoreYes — npm start, no install
tanstack-astryx-locoThe whole application: a Loco.rs (Rust) backend crate — migrations, dictionary, access rules, workflows, reports and hook handlers — and a TanStack Start + Astryx front end, manual.html — the application this guide buildsYes
enterprise-reportingTanStack Start server functions, list and detail routes, and a Kysely PostgreSQL migration, shaped to drop into an enterprise_reporting_rust checkoutNo, by design
What the reporting target does not compile

It generates less on purpose: that repository already holds auth, two layers of RBAC, an encrypted data-source connection manager, an NL→SQL pipeline, a job runner and a UI shell, and a generated copy of any of them would be a fork of a moving part. So workflows and rbac are not compiled there, and rules are emitted as GoRules JDM but not wired up. The generated handlers call requireAuth(), which establishes who is calling; adding requirePermission() and the role strings is an integration step you do by hand.

Write the model in full anyway. What this target skips is still what the checker validates, what the viewers render, and what tanstack-astryx-loco compiles from the very same file.
