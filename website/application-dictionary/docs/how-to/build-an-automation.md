# Build an automation

1. Open [Automations](../windows/automations.md) and choose **+ New automation**.
2. Under **When this happens**, choose the **Record type** and the event (*is created*, *is updated*, …).
3. Choose **Add a condition or an action** to add a check (*only if*) and then each step (*then*).
4. Name any step that produces a value so later steps can use it.
5. Fix anything the line under the title reports, then choose **Publish**.

![A new automation](/img/automation-new.jpg)

The built-in guide in the middle column explains each step type with examples; **Test runs** and **Reading a failure** describe how to check one.
