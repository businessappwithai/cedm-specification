# Move an entity to another dashboard block

1. Open [Entity Categories](../windows/categories.md).
2. To create a block, choose **New Category**, give it a **Name**, **Code**, **Icon**, **Colour** and **Sequence**, and save.
3. In **Entity Assignment**, change the **Category** of an entity.
4. Reload the dashboard: the entity's card is in its new block.
