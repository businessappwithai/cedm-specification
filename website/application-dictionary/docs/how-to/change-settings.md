# Change a setting

1. Open [System Configuration](../windows/system.md).
2. Click the setting (for example `app_name`).
3. Choose **Edit**, change **Value**, choose **Save Changes**.

![A setting record](/img/system-record.jpg)

`app_name` changes the name in the header. `ai_base_url`, `ai_model` and `ai_api_key` choose the server the **Ask** assistant talks to: business data is sent to it, so point it only at a server you trust.
