# Administration

Everything an administrator needs is on the dashboard's **Application Dictionary** section. These windows are the same in every application; what differs is the data in them. This application's own lifecycles, rules, processes, access and reports are documented in the pages that follow.

| Window | Address | What it is for |
| --- | --- | --- |
| **Business Rules** | `/admin/rules` | Create, edit and switch off the business rules that run when records are saved. |
| **Workflow Designer** | `/admin/workflow-definitions` | Design the multi-step processes the application runs. |
| **Workflow Monitor** | `/admin/workflows` | Watch processes as they run and read what each step did. |
| **Automations** | `/admin/automations` | Build when-this-then-that chains without writing a process. |
| **Audit Log** | `/admin/audit` | Read the tamper-evident trail of every change and verify its chain. |
| **Table and Column** | `/admin/tables` | Add or change a business table and its columns. |
| **Window, Tab and Field** | `/admin/windows` | Arrange the windows, tabs and fields users see. |
| **Entity Categories** | `/admin/categories` | Group windows on the dashboard and menu. |
| **Element** | `/admin/elements` | Reusable field names, labels and help text shared across tables. |
| **Reference** | `/admin/references` | Maintain the field types and the lists and lookups behind the dropdowns. |
| **Field Layout Manager** | `/admin/fields` | Arrange a window's fields into groups and columns. |
| **Reports** | `/admin/reports` | Run the analytical reports this application ships with. |
| **User Administration** | `/admin/users` | Create accounts, reset passwords and grant roles. |
| **Role Administration** | `/admin/roles` | Define roles and decide which windows each may open and change. |
| **System Configuration** | `/admin/system` | Application-wide settings. |
