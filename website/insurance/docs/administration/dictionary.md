# Application Dictionary

Every screen in Insurance is read from the **Application Dictionary** at run time: the windows you open, the tabs and fields on them, their labels and help text, which dropdown a field uses, and who may see it. An administrator can change the dictionary and the change appears on the next request, with no rebuild.

This application's dictionary holds **47 tables**, **312 columns**, and one window for each of the 47 entities that are not lines of another.
