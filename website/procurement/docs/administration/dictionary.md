# Application Dictionary

Every screen in Procurement and Sourcing is read from the **Application Dictionary** at run time: the windows you open, the tabs and fields on them, their labels and help text, which dropdown a field uses, and who may see it. An administrator can change the dictionary and the change appears on the next request, with no rebuild.

This application's dictionary holds **97 tables**, **735 columns**, and one window for each of the 88 entities that are not lines of another.



The full guide, with every window and a how-to for each task, is the shared [Application Dictionary manual](pathname:///application-dictionary/).
